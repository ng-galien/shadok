# Shadok agent — visual proposal

**Passez votre application Kubernetes existante en live, sans recréer son déploiement.**

Shadok connects the application your platform already deploys to the successful builds produced by a developer or a CI runner. The platform owns Kubernetes operations; the client publishes file changes through a gateway. The live session is reversible.

The proposed [SVG glyph](assets/shadok-agent.svg) keeps the rounded silhouette, long beak, expressive eyes and thin legs associated with Jacques Rouxel's Shadoks. A cyan visor and a small antenna introduce the software-agent character without replacing the bird with a generic robot. The drawing uses editable paths, no embedded bitmap, font or external dependency. The warm white body remains visible on light and dark README backgrounds.

Visual reference: [Les Shadoks et les Gibi-infos, Jacques Rouxel — Artcurial](https://www.artcurial.com/ventes/4387/lots/36-a). Historical context: [MIAM exhibition guide, in partnership with aaa production and INA](https://miam.org/wp-content/uploads/2017/04/guide_visiteur-4.pdf). This is a new adaptation proposal for the repository, not an official Shadoks illustration or an affiliation claim.

The repository and executable retain the spelling **Shadok**. The illustration's agent motif is a visual identity, not a claim that an AI agent is required to run the operator.
